# Fix

## Триггер

Пользователь пишет `fix` или `исправь`.

## Сценарий

1. **Собрать замечания.**
   Взять список замечаний из текущего контекста чата. Если пользователь указал Notion-ссылку — `notion-fetch` и взять оттуда. Каждое замечание должно содержать: файл, что не так, что нужно.

2. **Исправить по списку.**
   Для каждого замечания:
   - Прочитать указанный файл
   - Внести минимальные правки (не переписывать то, что работает)
   - Комментарии на русском

3. **Проверить.**
   Запустить `npm run test` и `npm run lint`. Показать результат.

4. **Обновить Phase.**
   Через `notion-update-page` установить Phase → Fix для текущей задачи.

5. **Предложить следующий шаг.**
   Если тесты и линт зелёные — предложить `check`. Если есть ошибки — показать и предложить доправить.

## Важно

- Не выходить за рамки списка замечаний.
- Не рефакторить код, который не упомянут в замечаниях.
- Если замечание непонятно — уточнить у пользователя, а не додумывать.
- Если замечание требует архитектурных изменений — сообщить что нужна эскалация на Opus.
