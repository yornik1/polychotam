# Start Task

## Триггер

Пользователь пишет `start task <notion-url>` или `начни задачу <url>`.

## Сценарий

1. **Fetch задачу из Notion.**
   Вызвать `notion-fetch` по переданному URL. Извлечь: Task (название), Epic, Notes (DoD), Status, Phase, Assignee, Priority, Depends on.

2. **Проверить зависимости.**
   Если поле «Depends on» не пустое — для каждой связанной задачи `notion-fetch` и проверить Status = Done. Если есть незавершённые — сообщить пользователю и остановиться.

3. **Обновить статус.**
   Через `notion-update-page` установить Status → In Progress. Если Phase пустая — установить Phase → Dev.

4. **Загрузить контекст проекта.**
   Прочитать `src/types/contracts.ts` и `docs/PROJECT_STRUCTURE.md`. Не перечитывать, если уже в контексте.

5. **Найти спеку (если есть).**
   Поискать в `docs/archive/specs/` файл, относящийся к текущему эпику. Если не найден — проверить дочерние страницы задачи в Notion. Если спеки нет — пропустить.

6. **Начать TDD.**
   На основе DoD из Notes написать первый falling test. Сообщить пользователю что делаешь и какой тест написан.

## Важно

- Не начинать реализацию без теста.
- Комментарии в коде на русском.
- Типы из `src/types/contracts.ts`, не дублировать.
- Коммит-сообщение формировать из Notes задачи.
