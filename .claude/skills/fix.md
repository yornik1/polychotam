# Fix

Правки по замечаниям из ревью или проверок.

## Использование

Пользователь пишет: "fix" или "исправь"

## Сценарий

1. **Собрать замечания**
   - Взять список из текущего контекста чата
   - Если есть конкретные файлы/строки — использовать их

2. **Исправить по списку**
   - Для каждого замечания:
     - Прочитать файл
     - Минимальные правки (не переписывать то, что работает)
     - Комментарии на русском

3. **Проверить**
   - Запустить `npm run test` и `npm run lint`
   - Показать результат

4. **Предложить следующий шаг**
   - Тесты и линт зелёные → предложить check
   - Ошибки → показать и предложить доправить

## Важно

- Не выходить за рамки списка замечаний
- Не рефакторить код, который не упомянут
- Если замечание непонятно — уточнить, не додумывать
- Архитектурные изменения → обсудить с пользователем
