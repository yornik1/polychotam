# Check

Проверка результата задачи: build, тесты, сервисы, чеклист DoD.

## Использование

Пользователь пишет: "check" или "проверь"

## Сценарий

1. **Собрать проект**
   - Запустить `npm run build`
   - Если ошибки — показать и остановиться

2. **Прогнать тесты**
   - Запустить `npm run test`
   - Показать результат

3. **Запустить сервисы**
   - Проверить `docker compose ps`
   - Если не запущены — `docker compose up -d`
   - Запустить `npm run start:dev` в фоне
   - Дождаться "Application is running"

4. **Проверить Definition of Done**
   - HTTP-проверки → curl, показать результат
   - Проверка файлов → убедиться что файл существует
   - Проверка БД → запрос через TypeORM или psql
   - Браузер → сообщить пользователю URL

5. **Вывести результаты**
   - Показать что прошло / требует ручной проверки / не прошло
   - Для каждого пункта — краткое пояснение

6. **Предложить следующий шаг**
   - Всё ок → предложить создать коммит
   - Есть проблемы → предложить исправления

## Важно

- Не убивать dev-сервер после проверки
- Показывать реальный вывод команд
- Если DoD неоднозначный — уточнить у пользователя
