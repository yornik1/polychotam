# Polychotam Skills

Доступные скиллы для работы с проектом.

## Workflow скиллы

### check
Проверка результата задачи: build, тесты, сервисы, чеклист DoD.

**Триггер:** "check" или "проверь"

### fix
Правки по замечаниям из ревью или проверок.

**Триггер:** "fix" или "исправь"

### review-task
Ревью, коммит после завершения задачи.

**Триггер:** "review task" или "ревью"

## Обучающие скиллы

### quiz
Socratic tutor для проверки понимания кода через вопросы.

**Триггер:** "quiz" или упоминание конкретного файла/модуля для разбора

## Использование

Просто напиши триггерное слово в чате, и Claude активирует соответствующий скилл.

Пример:
- "check" — запустит проверку проекта
- "fix" — начнёт исправление замечаний
- "review task" — подготовит коммит
- "quiz" — начнёт Socratic-сессию
