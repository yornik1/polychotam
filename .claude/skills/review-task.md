# Review Task

Ревью, коммит после завершения задачи.

## Использование

Пользователь пишет: "review task" или "ревью"

## Сценарий

1. **Показать изменения**
   - Запустить `git diff --stat` и `git diff`
   - Краткая сводка: файлы, строки

2. **Автоматические проверки**
   - Параллельно: `npm run lint`, `npm run test`, `npm run build`
   - Показать результат

3. **Проверка качества кода**
   - По diff проверить:
     - Нет `any` в TypeScript
     - Нет `console.log` (только NestJS `Logger`)
     - Комментарии на русском
     - Типы из `src/types/contracts.ts` (не дублированы локально)

4. **Предложить коммит**
   - Сформировать коммит-сообщение в формате conventional commits
   - Показать и спросить подтверждение

5. **Выполнить коммит**
   - После подтверждения: `git add` + `git commit`

6. **Предложить следующий шаг**
   - Задача готова к ревью
   - Предложить следующую задачу или push

## Важно

- Не коммитить без подтверждения пользователя
- Не коммитить .env, credentials
- Если lint/test/build падают → предложить fix
